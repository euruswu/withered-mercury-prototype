# 接入《朽然》与验证说明

## 版本与范围

- 开发目标：Godot **4.7.2 Standard**，GDScript，Compatibility 渲染器。
- 独立桌面 2D 谜题。建议横向窗口，默认 1120 × 800。
- 三环各六档，初始布局、12 段管路和固定核心 / 储液罐端口均沿用已确认的 HTML 原型。
- 连通判断和视觉动画分离：吸附前仅改变显示角度，吸附后才更新整数档位。
- 试流期间锁定旋转，复位可随时中断。切出应用时取消未完成拖动并回到拖动前档位。
- 双语文字与字体包含在工程里，运行不需要网络。

## 场景接口

将 `scenes/mercury_puzzle.tscn` 实例化到房间的全屏调查面板里。

根节点提供：

```gdscript
signal solved
signal readiness_changed(is_ready: bool)

func reset_puzzle() -> void
func start_test() -> void
```

`solved` 在一次试流经过核心并返回储液罐后发出。它仅表示管道校准成功；时间跳转仍由主体游戏在玩家正确输入 checkpoint 后触发。

`readiness_changed` 用于同步当前机器是否就绪。开始调整、重新试流或复位会变为 `false`；完成正确回路会变为 `true`。如果正式游戏希望解开后永久锁定机器，可以在收到 `solved` 后关闭此调查面板并保存房间进度。

独立玩具中通关后允许重新调整，不会永久锁定。没有跨时间物品、剧情或笔记本状态。

## 验证覆盖

`tests/test_model.gd` 将全部 **216** 种档位组合的结果拼成签名，与移植前从原 HTML 原型取得的 SHA-256 比较。签名包括：结果类型、是否经过核心、停流位置、每段管路及其流动方向。并验证唯一解、通过核心但回流失败的状态、完整旋转一周的等价性。

`tests/test_puzzle.gd` 实例化真实场景，通过 Godot 输入系统派发鼠标事件，验证：

- 单击恰好转一格；顺 / 逆时针拖动吸附；拖动释放不追加单击。
- 切出应用取消拖动；键盘选择与转动使用真实输入事件验证。
- 试流期间的输入锁定。
- 试流中复位、通关后继续调整与重玩。
- 成功信号只在经过核心且返回储液罐后发出。
- 所有 216 种状态的动画管段在几何上首尾相接。
- 中文、英文、初始 / 失败 / 通关画面可通过可选截图参数检查。

需要截图时，在有图形显示的环境中运行：

```sh
godot --audio-driver Dummy --script tests/test_puzzle.gd -- --capture=/absolute/output/path
```

自动测试不能代替真实 Mac 上的鼠标 / 触控板手感验收。若发现问题，请给出操作顺序与 Godot 底部 Debugger 的首条错误。

## 字体扩展

当前 `MercurySans.ttf` 仅包含原型界面所需文字。新增中文文案时，应重新制作字体子集或替换为完整的 Noto Sans SC；否则新汉字可能依赖操作系统回退字体。字体来源与授权见 `assets/fonts/README.md`。
