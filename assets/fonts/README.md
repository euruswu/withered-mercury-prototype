# Mercury Sans

Source: [Noto Sans SC, Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc).

The variable source font was instantiated at weight 400 and subset to this prototype's GDScript text plus printable ASCII using fontTools. Font name records 1, 4 and 6 were renamed to Mercury Sans / MercurySans-Regular. The SIL Open Font License 1.1 is included in `OFL.txt`.

The font is bundled so Chinese text renders without installing system fonts. New UI text may need an expanded subset or a full replacement font.
